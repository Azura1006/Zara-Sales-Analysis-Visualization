# Zara-Sales-Analysis-Visualization

## Project Overview

This project analyzes Zara sales data using Python and presents insights through an streamlit web application.


## 🛠️ Tools & Technologies

* Python (Pandas, Matplotlib, Plotly)
* Streamlit (for interactive app)

---

## 💻 Streamlit App

The app provides multiple analysis modules:

Category Analysis
Product Position Analysis
Price Analysis
Promotion & Seasonal Effects
Gender Analysis
